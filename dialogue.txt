# CHUMBO'S BIRTHDAY: everything anyone says, and the words to every song, level by level.
#
# Change the words and the game says the new ones. (The voices and the singing for anything
# you change are made again automatically when the game is published.)
#
# DIALOGUE looks like this:
#
#     name (who): what they say
#
#   name   the game finds the line by this, so don't change it (or the game won't find it).
#   who    who says it, which picks the voice and the box:
#              host, evil host, grey host, announcer, evil announcer, chumbo, rocko,
#              everyone, dijimon, evil dijimon, tony honk, pip, taxman, sarge
#   what they say:
#              \n   starts a new line in the same box
#              \\n  starts a new box (the next box comes up after this one)
#
#   For example   hello (host): Hello \n there   is one box, "Hello" on top and "there" under it,
#   and           hello (host): Hello \\n there  is two boxes, "Hello" and then "there".
#
# SONGS look like this:
#
#     song karaoke - verse:
#         Mi{mee}-ka{kah}-ke{keh} on the stage to-night,
#         teal twin-tails swing-ing in the light!
#
#   Each line under it is one window of the words at the bottom of the screen (\n and \\n
#   work there too). Split words into the syllables that get sung with - (birth-day). Each
#   sung line needs the same number of syllables as before: the tune has one note for each.
#   {...} after a syllable says how to sing it.
#   "(2nd time)" is the words for the second time round, "(evil)" the evil version of the song.
#
# Lines starting with # are notes for people, and the game ignores them.
