The one file from Godot 4.7.2's official export templates that the web build needs
(`web_nothreads_release.zip`, unchanged, sha256 d3ee2f08cef0cf3cf6678a6355a92a8db48ccdd35cbd2e8bfd5f0e8a0b4032a0),
kept here so publishing doesn't have to download the whole 1.3 GB templates file from GitHub,
which often times out. `.gdignore` keeps Godot from importing this folder.
